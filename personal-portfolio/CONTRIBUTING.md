# Contributing Guide

Thank you for your interest in contributing to the Personal Portfolio Website!

## How to Contribute

### Reporting Issues
1. Check existing issues first
2. Describe the problem clearly
3. Include steps to reproduce
4. Share your environment details

### Submitting Features
1. Fork the repository
2. Create a feature branch: `git checkout -b feature/amazing-feature`
3. Make your changes
4. Commit: `git commit -m 'Add amazing feature'`
5. Push: `git push origin feature/amazing-feature`
6. Open a Pull Request

## Development Guidelines

### Code Style
- Use consistent indentation (2 spaces)
- Follow JavaScript naming conventions
- Write clear, descriptive variable names
- Add comments for complex logic

### Frontend
- Keep CSS organized and responsive
- Test on multiple screen sizes
- Use semantic HTML5 elements
- Optimize images before adding

### Backend
- Follow RESTful API conventions
- Validate all inputs
- Use proper HTTP status codes
- Write descriptive error messages

### Commit Messages
```
Feature: Add user authentication
Fix: Correct form validation issue
Docs: Update API documentation
```

## Testing
- Test your changes thoroughly
- Run validation tests
- Test on different browsers
- Check responsive design

## Pull Request Process
1. Update documentation
2. Add tests if applicable
3. Ensure no breaking changes
4. Add clear PR description
5. Request review from maintainers

## Code of Conduct
- Be respectful and inclusive
- Provide constructive feedback
- Help others learn and grow
- Report inappropriate behavior

## Questions?
- Open an issue for questions
- Check documentation first
- Ask in discussions section

Thank you for helping make this project better! 🙏
